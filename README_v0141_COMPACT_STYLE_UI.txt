파란 논문 v0.14.1 - 글자·문단 스타일 UI compact

수정 대상:
참고문헌 양식 관리 > 3. 글자·문단 스타일

변경:
- 각 속성이 한 줄씩 길게 차지하던 느낌을 줄임
- 데스크톱에서 최대 6열 compact grid
- 글꼴/크기/장평/자간/줄간격/여백/내어쓰기/문단간격/정렬을
  약 2줄 수준에 배치
- 각 항목은 '레이블 + 입력칸'을 가로로 배치
- 입력 높이도 축소
- 화면 폭이 줄어들면 3열, 모바일에서는 1열로 자동 변경

데이터 구조나 저장 방식은 변경하지 않았습니다.
스타일 값/참고문헌 출력/Word/HWP 복사 기능은 v0.14.0과 동일합니다.
