파란 논문 v0.13.2 - 참고문헌 기본 스타일 변경

사용자가 제공한 아래한글 '참고문헌' 스타일 정보를 기준으로,
JSON에 글자/문단 스타일 값이 없을 때 다음 값을 기본값으로 사용합니다.

문단 모양
- 왼쪽 여백: 6 pt
- 오른쪽 여백: 0 pt
- 첫 줄: 내어쓰기 30 pt
- 정렬: 양쪽
- 줄 간격: 180 %
- 문단 위: 0 pt
- 문단 아래: 0 pt

글자 모양
- 글꼴: HCR Dotum
- 크기: 10 pt
- 장평: 100 %
- 자간: 0 %

추가 변경
- 스타일 설정 UI에 오른쪽 여백 추가
- 스타일 설정 UI에 장평 추가
- 스타일 설정 UI에 자간 추가
- JSON에도 rightIndentPt / fontScalePercent / letterSpacingPercent 저장
- 기존 JSON에 이 값들이 없으면 위 기본값으로 자동 보완
- 출력/서식 포함 복사 HTML에도 오른쪽 여백, 장평, 자간 반영

참고:
- '다음 스타일: 참고문헌'은 아래한글 내부의 스타일 연결 속성이므로
  웹 HTML 복사 데이터에는 직접 적용하지 않습니다.
