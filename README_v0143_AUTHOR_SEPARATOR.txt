파란 논문 v0.14.3 - 참고문헌 형식별 저자 구분자

핵심 원칙

1. 시트의 '저자' 값
항상 중간점(·)으로 저자를 구분한다고 전제합니다.

예:
  김철수·이영희·박민수
  Smith, J.·Doe, A.

시트 데이터 자체는 변경하지 않습니다.

2. 참고문헌 양식 관리
6개 형식 각각에 '저자 구분' 선택 항목을 추가했습니다.

선택 가능:
- 중간점: ·
- 쉼표: , + 뒤 공백
- 세미콜론: ; + 뒤 공백
- 앤드: 앞뒤 공백 + & + 뒤 공백

예:
학회지_국내 = 중간점
학회지_해외 = 쉼표

처럼 같은 양식 그룹 안에서도 서로 다르게 설정할 수 있습니다.

3. JSON 저장
각 referenceFormatGroups 항목에 다음 데이터가 저장됩니다.

  "authorSeparators": {
    "journalKo": "·",
    "thesisKo": "·",
    "bookKo": "·",
    "journalEn": ", ",
    "thesisEn": ", ",
    "bookEn": ", "
  }

schemaVersion은 7로 증가했습니다.

기존 JSON에는 authorSeparators가 없으므로 자동 마이그레이션합니다.
기존 출력이 갑자기 달라지지 않도록 기존 그룹은 모든 형식의
구분자를 기본 '·'로 채웁니다.

4. 참고문헌 출력
AU 토큰을 치환할 때만 구분자를 변경합니다.

시트:
  김철수·이영희·박민수

학회지_국내 구분자 = ·
출력:
  김철수·이영희·박민수

학회지_해외 구분자 = ", "
출력:
  김철수, 이영희, 박민수

서양 저자명 내부의 쉼표는 유지합니다.

시트:
  Smith, J.·Doe, A.

쉼표 구분 출력:
  Smith, J., Doe, A.

5. 기존 기능
템플릿, 이탤릭, 글자·문단 스타일, Word/HWP 분리 복사,
Mac 한글 PDF 파일명 대응은 그대로 유지합니다.
