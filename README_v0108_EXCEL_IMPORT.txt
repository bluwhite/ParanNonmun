기존 참고문헌 Excel 확인 결과

- 제목 행: 4행
- 컬럼:
  확인(*), 저자, 출판연도, 논문명, 학술지명, 권, 호,
  학회명, 시작페이지, 끝페이지, 메모, PDF

가져오기 방식
1. 논문 폴더를 연결합니다.
2. '엑셀 가져오기' 버튼을 누릅니다.
3. 기존 Excel 파일을 선택합니다.
4. 모든 Excel 시트의 첫 20행을 검사합니다.
5. 현재 파란 논문 시트의 컬럼명과 비교해 가장 잘 맞는 제목 행을 찾습니다.
   - '논문명'이 반드시 포함되어야 함
   - 현재 컬럼명과 3개 이상 일치해야 함
6. 제목 행 아래의 데이터를 읽습니다.
7. Excel 열 순서와 현재 파란 논문의 열 순서는 달라도 됩니다.
   컬럼 이름으로 연결합니다.
8. 현재 목록의 마지막 행 뒤에 추가합니다.
   기존 데이터는 삭제하거나 덮어쓰지 않습니다.
9. 현재 파란 논문에 사용자가 만든 커스텀 열이 있고
   Excel에도 같은 이름의 열이 있으면 함께 가져옵니다.
10. Excel의 PDF 값이 '.pdf'로 끝나면 현재 규칙에 맞춰 확장자는 제거합니다.

가져오기 전에 확인창에서
- 파일명
- Excel 시트명
- 제목 행 번호
- 일치한 컬럼
- 가져올 행 수
를 보여줍니다.
