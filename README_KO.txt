GitHub Pages용 PDF 새 창 편집 + 원본 덮어쓰기 테스트
====================================================

핵심 목표
---------
1. 메인 목록에서 PDF를 누르면 새 창에서 연다.
2. 새 창 위쪽에 '원본에 저장' 버튼이 항상 보인다.
3. 형광펜/메모 후 '원본에 저장'을 누르면
   기존 파일 경로와 기존 파일 이름 그대로 덮어쓴다.
4. '복사본 저장'은 같은 폴더에 *_annotated.pdf를 만든다.

중요
----
- PDF는 GitHub로 업로드되지 않습니다.
- GitHub Pages에는 프로그램 코드만 있습니다.
- 실제 PDF 읽기/쓰기는 Chrome/Edge와 사용자의 로컬 폴더 사이에서 이루어집니다.
- 처음 폴더를 선택할 때 읽기/쓰기 권한을 요청합니다.

GitHub Pages 배포
-----------------
1. ZIP 압축을 풉니다.
2. 저장소 루트에 파일 전체를 업로드합니다.
3. Commit changes
4. 이미 GitHub Pages가 main / root에서 배포 중이라면 별도 설정은 필요 없습니다.
5. 배포 완료 후 페이지에서 Ctrl+F5(Windows) 또는 Cmd+Shift+R(Mac)로 강력 새로고침하세요.

새 저장소라면
------------
Settings -> Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)

테스트 순서
-----------
1. 메인 화면에서 [논문 폴더 선택]
2. PDF가 있는 폴더 선택
3. 목록에서 [새 창에서 편집]
4. 새 창에서:
   - 형광펜: 마우스로 드래그
   - 메모: [메모] 클릭 -> 메모 입력 -> PDF 위치 클릭
5. [원본에 저장]
6. 창을 닫고 같은 PDF를 다시 열어 표시가 남았는지 확인
7. 탐색기/Finder에서도 파일 이름과 위치가 그대로인지 확인

주의
----
현재 형광펜/메모는 PDF 표준 Annotation 객체가 아니라
페이지 위에 그래픽으로 그려 넣는 방식입니다.
그래서 저장한 뒤 Chrome, Edge, Acrobat, Preview 등 어디서 열어도 보입니다.
