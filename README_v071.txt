- shared.js
- index.html
- styles.css
- main.js

기능
- 현재 연결 폴더와 하위 폴더의 모든 PDF 메모 검색
- 표준 PDF Text / FreeText 주석 검색
- 결과: 파일 이름 / 페이지 / 메모 내용
- 검색어가 비어 있으면 전체 메모
- 검색어가 있으면 메모 내용 부분일치
- 결과 파일명을 누르면 해당 PDF의 해당 페이지로 이동
- 검색 진행상황 표시
