다운로드 폴더
- 논문 폴더와 별도로 FileSystemDirectoryHandle을 IndexedDB에 기억합니다.
- 버튼을 누르면 PDF를 내려받는 폴더를 지정합니다.
- 다음 실행에서도 폴더를 기억하며 브라우저가 필요할 때만 권한을 다시 요청합니다.

PDF 연결
1. 시트에서 작업할 행의 아무 셀이나 선택
2. 선택 행의 '논문명' 확인
3. 논문명이 비어 있으면 오류 메시지를 내고 중단
4. 지정한 다운로드 폴더에서 PDF 선택
5. 선택한 PDF를 논문 폴더 최상위로 복사
6. 논문명을 파일명으로 사용
7. 파일명에 사용할 수 없는 문자
   < > : " / \ | ? * 및 제어문자
   는 공백으로 변경하고 연속 공백을 정리
8. 같은 이름이 이미 있으면
   논문명 (2).pdf, 논문명 (3).pdf ...
   로 덮어쓰기를 방지
9. PDF 열에는 확장자(.pdf)를 제외한 실제 파일명 기록
10. 시트 기록까지 성공한 뒤 다운로드 폴더의 원본 PDF 삭제

PDF 열기
- 선택 행의 PDF 열 값을 읽어 논문 폴더의 실제 PDF를 찾습니다.
- 기존 pdf-editor/index.html을 열어
  연속 페이지 보기, 형광펜, 메모, 저장 기능을 그대로 사용합니다.
- PDF 셀을 빠르게 두 번 클릭해도 같은 편집기로 엽니다.

안전 장치
- 다운로드 폴더가 지정되지 않으면 PDF 연결을 시작하지 않습니다.
- 파일 선택창에서 다운로드 폴더 밖의 PDF를 선택하면 이동하지 않습니다.
- 시트의 PDF 값 기록에 실패하면 새로 복사한 대상 PDF를 제거하고 원본은 남깁니다.
- 원본 삭제만 실패한 경우 연결은 유지하고 경고 메시지를 표시합니다.
