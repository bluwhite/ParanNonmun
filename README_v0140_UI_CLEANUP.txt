파란 논문 v0.14.0 - UI 정리 및 시트 더블클릭 PDF 열기 제거

1. 참고문헌 양식 관리 창 순서 변경
세로 흐름으로 정리:
  1. 양식 그룹
  2. 템플릿
     - 6개 템플릿 편집
     - 템플릿 코드 안내
  3. 글자·문단 스타일

기존 왼쪽 그룹 / 오른쪽 편집의 2열 배치를 없애고,
양식 그룹을 창 위쪽에 배치했습니다.

2. 시트 더블클릭 PDF 열기 제거
완전히 제거한 부분:
- Univer CellClicked 기반 더블클릭 판정
- 480ms 두 번 클릭 감지
- DOM dblclick fallback
- onPdfDoubleClick callback
- 관련 listener/disposable 상태

PDF 열기는 기존 상단/행 선택 기반 PDF 열기 기능을 사용합니다.

3. 메인 상단 '참고문헌 출력' 버튼 강조
폴더가 연결되어 버튼이 활성화되면:
- 파란 배경
- 흰 글자
- 굵은 글씨
- 조금 더 큰 padding
으로 표시하여 다른 보조 버튼보다 눈에 띄게 했습니다.

4. 기존 기능 유지
- 참고문헌 양식 그룹 추가/복제/삭제
- 템플릿 Ctrl+I 이탤릭
- 템플릿 코드 안내
- 글자·문단 스타일
- Word/HWP 분리 복사
- 한글 Ctrl+Alt+V -> 인터넷 문서
- v0.13.9 이탤릭 경계 공백 보존
