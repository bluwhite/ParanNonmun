참고문헌 출력
1. 양식 그룹 선택
   - 경사대양식 / 양식1 / 양식2 / 사용자가 추가한 그룹
2. 확인(*) 값이 있는 행만 출력
3. 기본 출력 순서는 현재 시트 행 순서와 동일
4. 출력 결과는 직접 수정 가능
5. 템플릿의 <em> 이탤릭이 실제 결과에도 유지

확인(*) 처리
- 빈칸: 출력하지 않음
- *:
  기존 VBA 방식을 유지
  학술지명에 석사/박사/학위논문 포함 -> 학위_국내
  그 외 -> 학회지_국내
- 학회지_국내 / 학위_국내 / 단행본_국내
  학회지_해외 / 학위_해외 / 단행본_해외
  를 직접 입력하면 해당 템플릿 사용
- 그 외 값은 출력에서 제외하고 경고 표시

템플릿 치환
AU 저자
PY 출판연도
TI 논문명
JO 학술지명
VL 권
IS 호
PB 학회명/발행기관
SP 시작페이지
EP 끝페이지

VL+IS:
- 권+호: 제12권 제3호
- 권만: 제12권
- 호만: 제3집

VL(IS):
- 권+호: 12(3)
- 권만: 12
- 호만: 3

VL/IS:
- 권+호: 12/3
- 권만: 12
- 호만: 3

정렬
- 기본: 시트 순서
- [한글 먼저 정렬]:
  저자(없으면 논문명)를 기준으로
  한글 자료를 먼저 가나다순 정렬
  그 뒤에 영문과 기타를 한 그룹으로 정렬
- [시트 순서]:
  원래 시트 행 순서로 복원
- 정렬은 이미 생성된 결과 DOM 순서만 바꾸므로
  사용자가 출력 결과를 직접 수정한 내용은 유지

복사
- [서식 포함 복사]:
  text/html + text/plain을 함께 Clipboard에 기록
  이탤릭을 포함해 Word/아래한글 등에 붙여넣을 수 있도록 함
  ClipboardItem을 지원하지 않는 경우 브라우저 rich-copy 방식으로 fallback
- [일반 텍스트 복사]:
  서식을 제외한 텍스트만 복사

출력 순서 정확성
- 참고문헌 출력창을 열기 직전에 Univer 시트를 flush하여
  현재 보이는 행 순서대로 paperData.papers를 다시 생성한 뒤 출력합니다.
