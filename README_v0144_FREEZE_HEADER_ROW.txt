파란 논문 v0.14.4 - 논문 목록 제목행 기본 고정

기존 새 시트 생성 로직에는 이미 첫 행 freeze 설정이 들어 있었습니다.
이번 버전에서는 기존 파란논문.json에 저장된 sheetSnapshot에도
시트를 열 때 최소 첫 번째 제목행이 고정되도록 보완했습니다.

동작:
- 고정 없음 -> 첫 행 1행 고정
- 이미 1행 고정 -> 그대로 유지
- 이미 2행 이상 고정 -> 그대로 유지
- 열 고정이 있으면 열 고정도 그대로 유지

수정 파일:
- shared.js
- paper-sheet/univer-sheet.js

index.html은 수정하지 않았으므로 GitHub에서 직접 수정한 index.html과
충돌하지 않습니다.
