파란 논문 v0.14.6 - PDF 형광펜/메모 삭제

편집 모드에서 기존 PDF 주석과 저장 전 새 주석을 모두 삭제할 수 있습니다.

- 형광펜: 영역 클릭 -> 선택 삭제 또는 Delete/Backspace -> 저장
- 메모: 작은 메모 아이콘 클릭 -> 선택 삭제 또는 Delete/Backspace -> 저장
- 저장 전 새 주석도 삭제 가능
- 실행 취소로 마지막 추가/삭제 작업 복원
- 편집 취소 시 삭제 표시를 포함한 모든 미저장 변경 취소
- 저장 시 PDF /Annots 배열에서 해당 Highlight/Text 주석 실제 제거

기존 v0.14.5의 작은 메모 hover UI와 주석 추가 형식은 유지합니다.
