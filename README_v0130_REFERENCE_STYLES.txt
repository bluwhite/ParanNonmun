기준 버전
- v0.12.4 FULL 통합본

교체 파일
- shared.js
- index.html
- styles.css

- reference-format/format-manager.js
- reference-output/output.js

1. 데이터 구조
schemaVersion 6

각 referenceFormatGroups 항목에:
- style: 그룹 공통 글자/문단 서식
- formatStyles: 6개 형식별 공통서식 사용 여부 + 개별 서식
이 추가됩니다.

기존 schemaVersion 5의 파란논문.json은 자동으로 6으로 마이그레이션됩니다.
기존 템플릿과 이탤릭은 그대로 보존됩니다.

2. 기본 공통 서식
- 글꼴: 바탕
- 크기: 10pt
- 줄간격: 160%
- 왼쪽 여백: 20pt
- 내어쓰기: 20pt
- 문단 위: 0pt
- 문단 아래: 0pt
- 정렬: 왼쪽

3. 참고문헌 형식 관리
양식 그룹마다 공통으로:
- 글꼴
- 글자 크기
- 줄간격
- 왼쪽 여백
- 내어쓰기
- 문단 위 간격
- 문단 아래 간격
- 정렬
설정 가능.

각 학회지_국내 / 학위_국내 / 단행본_국내 /
학회지_해외 / 학위_해외 / 단행본_해외 행에
[개별 서식] 체크가 추가됩니다.

체크하지 않으면 그룹 공통 서식을 사용합니다.
체크하면 해당 형식만 별도 글자/문단 서식을 지정합니다.

4. 참고문헌 출력
- 각 행에 해당하는 유효 서식을 실제 출력에 적용
- 화면 미리보기에도 글꼴/크기/줄간격/내어쓰기 반영
- 사용자가 출력 결과를 직접 수정 가능
- 정렬 시 수정 내용 유지

5. 복사 버튼
기존:
- 한글용 복사
- Word용 서식 복사
분리를 제거했습니다.

현재:
- 일반 텍스트 복사
- 서식 포함 복사

[서식 포함 복사]는 Word/아래한글 공용입니다.
- Word: 일반 Ctrl+V
- 아래한글: 반드시 Ctrl+Alt+V → 인터넷 문서

아래한글에서 일반 Ctrl+V를 하면 이탤릭/서식이 손실될 수 있으므로,
출력창에 이 안내를 노란색 강조 박스로 크게 표시합니다.

6. 이탤릭
템플릿 내부의 <em> 이탤릭은 복사 HTML을 만들 때 <i>로 변환해
Word/아래한글의 인터넷 문서 붙여넣기 호환성을 높였습니다.

7. Word 내어쓰기
출력 HTML은
- margin-left = 왼쪽 여백
- text-indent = -내어쓰기
- padding-left = 0
형태의 표준 hanging indent 구조로 생성합니다.
내어쓰기 값은 왼쪽 여백보다 크게 적용하지 않도록 제한합니다.
