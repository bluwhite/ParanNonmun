파란 논문 v0.10.4 - 논문 추가 화면 확인 기능

교체 파일
- shared.js
- paper-add/index.html
- paper-add/add.js
- paper-add/add.css

변경 내용

1. 오류 메시지 빨간색
AI / RIS / APA / MLA 파싱 오류와 논문 추가 저장 오류는
'추가될 정보' 오른쪽 상태 메시지가 빨간색으로 표시됩니다.
정상 메시지가 출력되면 다시 기본색으로 돌아옵니다.

2. 권·호·페이지 누락 확인
AI / RIS / APA / MLA 어떤 방식으로 분석했든 동일하게 적용합니다.

학술지명에 '학위논문'이라는 문자열이 포함되어 있지 않은 경우:
- 권 값이 비어 있으면 권 입력칸 노란색
- 호 값이 비어 있으면 호 입력칸 노란색
- 시작페이지가 비어 있으면 시작페이지 입력칸 노란색
- 끝페이지가 비어 있으면 끝페이지 입력칸 노란색

사용자가 값을 직접 입력하면 해당 칸은 즉시 정상색으로 돌아옵니다.
학술지명을 수정해 '학위논문'이 포함되면 네 칸의 노란색 경고를 해제합니다.
아직 아무 파싱도 하지 않은 빈 화면에서는 노란색 경고가 나타나지 않습니다.

3. 파싱 버튼 순서
[AI 분석] [RIS] [MLA] [APA]

APA는 가장 오른쪽에 위치하며 기존처럼 primary 메인 버튼입니다.

Groq API 설정, AI 진단 기능, RIS/APA/MLA 파서 기능은 그대로 유지됩니다.
