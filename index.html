로컬 PDF 폴더 연결

PDF는 업로드하지 않습니다. Chrome/Edge가 사용자가 직접 선택한 로컬 폴더만 읽습니다.

환경 확인 중

1. 논문 폴더 연결

아직 폴더를 선택하지 않았습니다.

현재 폴더없음
찾은 PDF0개

2. PDF 목록

선택한 폴더의 하위 폴더까지 검색합니다.

파일명상대경로크기
폴더를 선택하면 PDF 목록이 표시됩니다.

3. Google Sheets 연결 방식 테스트

나중에는 Google Sheets의 PDF 열기 링크가 이 웹앱에 상대경로를 전달하게 할 수 있습니다.

현재 형식:

브라우저 보안 정책 때문에 저장된 폴더의 권한을 다시 한 번 확인해야 할 때가 있습니다.

테스트 성공 기준

  1. 폴더 선택 창이 열린다.
  2. 선택한 폴더와 하위 폴더의 PDF가 목록에 나온다.
  3. PDF 보기를 누르면 새 탭에서 PDF가 열린다.
  4. 다시 접속한 뒤 이전 폴더 다시 열기가 동작한다.
  5. 상대경로를 넣어 특정 PDF를 열 수 있다.
