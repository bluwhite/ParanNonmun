PDF 메모·형광펜 저장 테스트

PDF는 서버에 업로드하지 않습니다. Chrome/Edge에서 선택한 로컬 폴더의 파일을 브라우저 안에서 읽고 수정본을 같은 폴더에 저장합니다.

아직 폴더를 선택하지 않았습니다.

PDF 0개

파일명상대경로크기
폴더를 선택하면 PDF 목록이 표시됩니다.

3. PDF 편집

형광펜: PDF 위에서 원하는 영역을 마우스로 드래그하세요.

이번 샘플에서 확인할 것

  1. 로컬 PDF를 웹앱 안에서 직접 표시할 수 있는지
  2. 형광펜 표시를 마우스로 추가할 수 있는지
  3. 한국어 메모를 원하는 위치에 추가할 수 있는지
  4. 수정본 새 파일로 저장을 누르면 원본 옆에 _annotated.pdf가 생성되는지
  5. 생성된 PDF를 Acrobat/Preview/Chrome에서 열었을 때 표시가 실제 PDF 안에 남아 있는지

이 테스트 버전은 PDF의 기존 주석 객체를 편집하는 방식이 아니라, 보이는 형광 표시와 메모 박스를 PDF 페이지에 새로 그려 저장하는 방식입니다.
